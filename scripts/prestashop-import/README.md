# Import на реалния каталог от PrestaShop

Този скрипт зарежда истинските продукти (имена, цени, описания, размери,
цветове, наличности, категории) от PrestaShop в новия CRM.

## 1. Постави файловете тук

Създай папка `data` до този файл и сложи вътре точно тези 4 файла (изтеглени
от PrestaShop → Разширени настройки → База данни → SQL мениджър →
съответната заявка → бутон за сваляне), преименувани точно така:

```
scripts/prestashop-import/data/products.csv
scripts/prestashop-import/data/categories.csv
scripts/prestashop-import/data/variants.csv
scripts/prestashop-import/data/images.csv
```

(Точните SQL заявки за всеки файл са дадени в чата - запази ги в SQL
мениджъра с различни имена, за да не се налага да ги пишеш наново всеки път.)

## 2. Пусни скрипта

От Terminal, в папката на проекта:

```
node scripts/prestashop-import/import.mjs
```

Ще видиш прогрес в конзолата. Отнема няколко минути за ~1000 продукта.

## 3. Резултат

- Продуктите вече са заредени в живата Next.js/Neon база - веднага видими в
  админ панела и сайта.
- Създава се файл `scripts/prestashop-import/mysql-import.sql` - готов за
  импорт в MySQL (php-site версията) през phpMyAdmin, когато решиш.

## Безопасно е за повторно пускане

Скриптът обновява продукти по SKU (не създава дубликати). Пусни го отново
по всяко време - например точно преди реалния launch на сайта, за да хванеш
последните промени в наличностите от все още живия PrestaShop магазин.

## Снимки

PrestaShop зарежда снимките динамично с JavaScript, затова не могат да се
извлекат през обикновен SQL/HTML експорт. Докато не заредим истинските
снимки (ще трябва ZIP на `img/p/` папката от cPanel), всеки продукт получава
същия цветен placeholder, който сегашният каталог вече ползва - лесно се
подменя по-късно от Admin > Продукти > Редакция > Снимки, без да е нужно да
пускаш скрипта отново.
